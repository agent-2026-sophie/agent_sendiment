# Cohen's Kappa（科恩卡帕系数）

## 一、指标含义

Cohen's Kappa 是统计学中衡量**两个评判者对同一组样本分类结果一致性**的指标。它扣除了"纯靠运气猜对"的部分，因此比简单的一致比例（如百分比一致）更严格、更可信。

在本评测场景中，用于衡量**机评与人工评分之间的一致性**：机评结果和人评结果越接近，Kappa 值越高，说明机评越可信。

### 取值范围与等级

取值范围在 **-1 到 1** 之间：

| 取值范围 | 一致性等级 |
|---|---|
| < 0.00 | 比随机猜测还差 |
| 0.00 – 0.40 | 一致性较差 |
| 0.40 – 0.60 | 中等一致 |
| 0.60 – 0.80 | 一致性良好 |
| 0.80 – 1.00 | 几乎完全一致 |

### 本评测中的判定标准

| 等级 | 阈值 | 说明 |
|---|---|---|
| 目标线 | ≥ 0.60 | 达到后算"良好一致" |
| 可接受线 | ≥ 0.45 | 最低门槛 |
| 本次实际值 | 0.8934 | 几乎完全一致，判定为达标（目标） |

## 二、计算方法

### 基本公式

$$\kappa = \frac{P_o - P_e}{1 - P_e}$$

其中：

- **P_o（Observed Agreement，观察一致率）**：机评和人评给出相同结论的样本数占总样本数的比例。
- **P_e（Expected Agreement，期望随机一致率）**：假设机评和人评各自独立打分、纯靠概率碰巧一致的比例，按每个类别在机评侧和人评侧的占比相乘后求和得到。

### 计算步骤

#### 步骤 1：构建混淆矩阵

假设分类为两类（如"合格 / 不合格"），统计机评与人评的交叉计数：

|  | 人评合格 | 人评不合格 |
|---|---|---|
| **机评合格** | a | b |
| **机评不合格** | c | d |

其中：
- a：机评合格且人评合格
- b：机评合格但人评不合格
- c：机评不合格但人评合格
- d：机评不合格且人评不合格

总样本数 N = a + b + c + d

#### 步骤 2：计算 P_o（观察一致率）

$$P_o = \frac{a + d}{N}$$

即机评与人评结果相同的样本占比。

#### 步骤 3：计算 P_e（期望随机一致率）

$$P_e = \frac{(a+b) \times (a+c) + (c+d) \times (b+d)}{N^2}$$

含义：
- 机评合格的比例 = (a+b) / N，人评合格的比例 = (a+c) / N，两者相乘即"随机情况下都判合格"的概率
- 机评不合格的比例 = (c+d) / N，人评不合格的比例 = (b+d) / N，两者相乘即"随机情况下都判不合格"的概率
- 两项相加即为随机碰巧一致的总概率

#### 步骤 4：代入公式计算 Kappa

$$\kappa = \frac{P_o - P_e}{1 - P_e}$$

- 当 P_o = P_e 时，κ = 0，表示一致性等同于随机猜测
- 当 P_o = 1 时，κ = 1，表示完全一致
- 当 P_o < P_e 时，κ 为负数，表示一致性比随机还差

## 三、举例

假设某次评测共 100 条样本，混淆矩阵如下：

|  | 人评合格 | 人评不合格 | 合计 |
|---|---|---|---|
| **机评合格** | 70 | 10 | 80 |
| **机评不合格** | 5 | 15 | 20 |
| **合计** | 75 | 25 | 100 |

计算：

1. P_o = (70 + 15) / 100 = 0.85
2. P_e = (80 × 75 + 20 × 25) / 100² = (6000 + 500) / 10000 = 0.65
3. κ = (0.85 - 0.65) / (1 - 0.65) = 0.20 / 0.35 ≈ 0.571

即该评测的 Cohen's Kappa 约为 0.571，属于中等一致水平。

---

## 四、总结

- **核心思想**：Kappa = 扣除随机因素后的真实一致性
- **优点**：消除了"碰巧猜对"的影响，比直接算一致百分比更客观
- **用途**：评估机评与人评、两个评测员、两种标注方案之间的一致性
- **本项目判定**：实际值 0.8934 ≥ 0.60 目标线，判定为达标（目标）
